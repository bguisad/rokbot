# RokBot 2026-11-27 更新说明

本次更新重点带来多端 1.3.0 升级、全新的 Linux 桌面端、批量图片下载、按场景分配模型、输入框快捷建议，以及 Android 端的单 Bot 模型指定和加号建群体验。

## 桌面端与网页版升级至 1.3.0

- **macOS、Windows 桌面端与网页版**默认升级至官方 **1.3.0** 基线，保留全部 RokBot 自托管能力（本地模型配置、会话排序、Bot 头像样式、用量统计、Tailcat 穿透与增量更新）。
- **旧版继续可用**：如暂不升级，macOS 仍接受 `1.2.3`，Windows 和网页版仍接受 `1.2.3` 与 `0.71.2`，可通过 `--version` 回退构建。

## 新增 Linux 桌面端

- 正式支持 **Linux x64 (`amd64`)** 与 **arm64 (`aarch64`)** 桌面客户端（基于官方 1.3.0）。
- 一次构建即可产出便携目录、通用 `.tar.gz` 压缩包，以及重品牌后的 Debian / Ubuntu `.deb` 安装包（安装至 `/opt/RokBot/rokbot`，并彻底移除上游 apt 源注册）。支持在 Linux 或 macOS 上跨平台构建，无需 `dpkg-deb`。
- 内置 Linux 版 `rokbot-tailcat`，与 macOS / Windows 共享全部桌面端功能，并支持通过 Host 管理页「客户端更新」发布及便携版 ASAR 增量热更新。

## 多选批量下载图片

- **桌面端（macOS、Windows、Linux）**：在对话或媒体查看器中可多选图片，一键保存到指定文件夹或打包导出为 ZIP。
- **网页版**：支持多选图片并直接打包为 ZIP 下载。
- **Android**：原生图片查看器新增多选批量保存，选中的图片直接保存到系统相册（`Pictures/RokBot`）。

## 输入框快捷建议

- 网页版与 Android 客户端的对话输入框上方新增上下文相关的快捷建议条，点击建议即可直接填入输入框。
- 建议由 Host 根据当前对话上下文生成，支持单独指定轻量快速模型；在尚未配置模型或请求失败时，自动回退为中英文预置建议，不影响正常发送。

## 按场景分配模型

- 管理页「对话模型」与 Android 模型设置页新增「场景模型」配置，可为以下 6 个场景分别指定模型档案与思考强度：
  1. **输入框建议**：生成对话输入框快捷建议（推荐轻量快速模型）；
  2. **上下文压缩**：长对话自动压缩与手动摘要；
  3. **记忆提取**：对话结束后的长期记忆提取；
  4. **自动审核**：敏感工具调用前的安全分类器；
  5. **子 Agent 执行**：委派子任务与电脑操作子 Agent；
  6. **定时任务**：例行任务与 Webhook 自动化执行。
- 任意场景留空时默认沿用「默认路由」，无需全部配置即可使用。

## Android 客户端体验增强

- **给单个 Bot 指定模型**：除模型设置页中的「单 Bot 模型路由」列表外，现在也可以在单个 Bot 的详情页直接点击「Bot 模型设置」，为该 Bot 指定专属模型与思考强度。
- **加号底部菜单与新建群组**：点击会话列表右上角「+」弹出贴合系统深浅色与中英文界面的原生底部菜单，可直接选择「新建 Bot」或「新建群组」，勾选多个 Bot 后在同一群聊中协作。

## 晚些时候的更新（第二版）

当天晚些时候发布了第二版，主要完善输入建议、Android 建群与模型设置界面，并补齐自建 Host 的若干能力。

### 输入建议更好用

- **可以关闭**：设置中新增输入建议总开关，以及单独的「AI 生成建议」开关。只想用常用语、不想调用模型时，关掉 AI 生成即可。
- **自定义常用语**：可以添加自己的常用语。常用语保存在 Host 上，桌面端、网页版与 Android 之间自动同步。
- **点击直接发送**：点击建议后直接发送，不再只是填入输入框。
- **更少打扰**：建议条只在输入框获得焦点时显示。
- **按上下文生成**：去掉了固定的预置文案。已有对话记录时，建议始终由模型根据当前上下文生成；空白会话只显示你的常用语。
- **修复总是显示预置文案的问题**：此前因请求超时过短，且沿用默认路由时思考强度偏高、响应慢，建议常常回退为预置文案。现已放宽超时，并在未单独配置「输入框建议」场景模型时自动使用最低思考强度，加快生成。

### Android 新建群组重新设计

- 建群流程与样式和桌面端保持一致：单页完成，顶部「To:」收件人栏选择成员。
- 一个群最多可加入 6 个 Bot，选择时可以直接在当前页面新建 Bot 并加入。
- 自动生成的群名规则与桌面端一致。
- 创建失败时会自动撤销已完成的步骤，不会留下不完整的群组。

### 模型设置界面统一

- 模型路由页（默认路由、场景模型、单 Bot 模型路由等）中的系统原生下拉框，换成与应用整体风格一致的下拉菜单；在 Android 上以底部选择面板呈现。

### 文件传输不再限制大小

- 在电脑与 Bot 工作区之间复制文件改为分块流式传输，默认不再限制单个文件大小，大文件也能稳定传输。
- Host 管理员如需限制，可通过环境变量 `ROKBOT_MAX_TRANSFER_BYTES` 设置上限。

### 自建 Host 能力补齐

- Bot 现在可以在自建 Host 上直接管理自身状态：更新与回忆长期记忆、修改例行任务并查看执行记录、更新个人资料与技能、创建新的 Agent、向用户发起表单填写、调整思考强度等。
- 修复任务跟踪（Tracked Tasks）结果为空的问题，跟踪的任务进度与结果现在可以正常显示。
- 说明：画布功能依赖官方云端的编译与托管服务，自建版暂不支持。

### 桌面图标与签名

- 桌面端图标统一为带浅蓝色底板的新样式，「关于」页面同步更新，Linux 窗口图标也一并替换。
- Android 正式版统一使用 RokBot 官方签名证书。构建时如缺少签名密钥或证书不符会直接报错，避免误装签名不同、无法覆盖升级的安装包。本版 Android 版本号为 `1.26.0-rokbot.10`，可直接覆盖升级上一版。

## 第三版：桌面端版本号升到 1.3.1

第三版只调整桌面端与网页版的对外版本号，功能与第二版相同。

- **桌面端与网页版版本号升到 1.3.1**：此前重新构建的客户端仍显示 1.3.0，与已安装的版本号相同，客户端的更新检查因此不会提示升级。现在 macOS、Windows、Linux 桌面端和网页版对外显示 1.3.1，已安装 1.3.0 的用户可以通过自建 Host 的「客户端更新」正常收到这次更新。
- 底层仍基于官方 1.3.0 安装包，补丁清单中会同时记录对外版本号和官方基线版本。
- 打包工具新增 `--app-version` 参数，用来指定对外版本号（不能低于官方基线版本）。

## 第四版：用量统计、Grok Bot 迁移、画布分享与 rokbot 命令行

第四版带来一批新功能和修复。桌面端与网页版对外版本号升到 **1.3.3**（底层仍基于官方 1.3.0），Android 版本号为 **`1.26.0-rokbot.11`**，可直接覆盖升级上一版。

### 用量统计

- Host 为每次模型调用记录所属 Bot、耗时和结果状态，并提供统一的用量报表接口。
- 网页管理后台、桌面端与网页版设置页、Android、iOS 都新增用量报表：按时间范围和条件筛选，查看趋势、按模型 / Bot / 场景的分布和逐条请求明细，并可导出 CSV。
- 接口与界面结构见仓库中的 `docs/usage-report.md`。

### 从 Grok Bot 迁移

- 新增迁移向导，把 Grok Bot 里的 Bot 搬到自己的 RokBot：Bot 列表、指令、头像、设置、记忆、技能、例程、参考资料，以及可选的聊天记录。
- 两种方式：桌面客户端一键读取本机缓存（也可在管理后台上传 ZIP）；或让 Grok Bot 按 RokBot 格式自行导出后上传到一次性地址，网页管理后台、桌面端、Android、iOS 都能使用。两种方式导入同一个 Bot 会自动合并，不会重复。
- 详细步骤见 `docs/migrate-from-grokbot.md`。

### 输入建议更快、更顺手

- **加载动效**：AI 生成建议时显示占位闪烁动效，不再空白等待。
- **行内补全**：输入时以浅色文字给出续写建议，按 Tab 或右方向键采纳；兼容输入法组字，可在设置中单独关闭。输入建议设置提升为一级入口。
- **按 Bot 隔离**：建议只跟随当前正在查看的 Bot，后台工作的其他 Bot 不会再抢走建议；过期或属于其他 Bot 的结果会被丢弃。
- **预取**：Bot 回复后 Host 提前生成并缓存下一轮建议，从输入框获得焦点到出现建议的时间由约 1960ms 降到约 165ms。
- 建议条更紧凑，最多 3 条，隐藏时不占空间。

### 管理后台分页

- 管理后台拆分为概览、模型、用量、客户端、设备、Bot、账号、系统等独立页面，左侧导航，窄屏下折叠为菜单。
- 每个页面只加载自己的模块，打开更快；旧链接会自动跳转到新页面。

### 许可证

- RokBot 自有内容改用 **RokBot Noncommercial License 1.0**（英文为准，附中文参考译文），内容与此前一致：仅限个人、自托管与非商业研究使用，禁止任何商业用途。
- 仓库中源自 ProkBot / ProkBot Plus 的部分继续适用原 ProkBot Noncommercial License 1.0，原文保留在 `LICENSES/ProkBot-Noncommercial-1.0.txt`。

### Android 冷启动修复

- 修复配对后冷启动有一定概率闪退的问题。
- 开屏只显示一个清晰的 RokBot logo：此前系统开屏图标分辨率过低被拉伸，先出现一个模糊的 logo 再切换为清晰的；现在从第一帧起就是清晰的 logo，浅色与深色模式一致。

### 画布

- 画布可以直接在 App 内打开（桌面端、网页版、Android、iOS），不必跳转浏览器。
- 新建画布默认私有；需要时可公开分享，复制或重新生成公开链接，取消分享后公开链接立即失效。
- Bot 详情页新增画布列表，可查看、打开和管理该 Bot 创建的画布。

### rokbot 命令行工具

- 新增 `rokbot` 命令，把部署、管理员初始化、环境检查、更新与回滚、本地打包收进一个命令，只需要 Node.js 20+，无第三方依赖。
- 可通过 `npx rokbot --help` 直接运行，或 `npm i -g rokbot` 全局安装。用法见 `docs/cli.md`。

## 第五版：修复检查更新返回 401、缓存写入统计与更新体验

第五版以修复为主。Android 版本号为 **`1.26.0-rokbot.13`**（versionCode 321213，签名证书 SHA-256 以 `46214d3d` 开头），可直接覆盖升级上一版，安装包 SHA-256 为 `ffda202719f76c8bf1a3f887df74789f86f5c0a4fcf273710ec0ed4a04e010f2`；桌面端仍为 **1.3.3**。本版 Android 包对应提交 `d3a2e30d`，不含 PR #4。通过自建 Host 的「更新」通道获取。

### 修复检查更新返回 401

- 通过 Tailcat 连接时，Android 的「检查更新」不再返回 401。
- 已配对时应用更新一律走当前 Host 连接并带上认证；Host 的更新代理直接在进程内处理指向自身的更新请求。

### 缓存写入统计修复

- Magpie 返回的 `cache_write_tokens` 计入缓存写入。
- Anthropic 缓存断点更稳定，`cache_ttl` 可配置。

### Tailcat

- 网络切换或回到前台后，自动恢复 Tailcat 隧道和本机回环路由。

### 更新体验

- Android 和桌面端支持发版推送、后台预下载（断点续传、校验）和「重启以更新」。
- APK 解析和增量包生成移到独立线程。

### 其他

- 用量页默认打开今天，刷新时显示加载状态。
- 修复 Windows PE 资源重写时 `.rsrc` VirtualSize 的问题。
- README 截图更新。
