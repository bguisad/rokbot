# RokBot 2026-11-28 更新说明

本版对应提交 `86c87a93`（PR #4 合入后的 main）。Android 版本号为 **`1.26.0-rokbot.14`**（versionCode 321214，签名证书 SHA-256 以 `46214d3d` 开头），可直接覆盖升级 321213 / 321212 / 321211；桌面端（macOS、Windows、Linux）与网页版升级到 **1.3.4**。通过自建 Host 的「更新」通道获取。

## 输入建议更懂你

- 输入建议按 Bot 学习你的使用习惯，不再出现与当前 Bot 无关的通用填充建议。
- 输入时在本地即时补全，不必等待网络请求。
- 建议条新增淡入、上浮动画，切换更顺滑。
- 设置中新增「学习输入习惯」开关，并可一键清除学习记录。
- 以上改动覆盖 Android、桌面端和网页版。

## 设置

- 「数据迁移」移到设置第一级，Android、桌面端和网页版都能直接找到。

## 自上一版 Android（321212）以来的其他修复

- 用量页默认打开「今天」，点击刷新时显示加载反馈。
- APK 解析和增量包生成移到独立线程，发布时 Host 不再卡顿（batch2 hotfix）。
- 缓存写入的 Token 用量统计正确（`cache_write_tokens` 计入缓存写入）。
- 网络切换或回到前台后，自动恢复 Tailcat 隧道和本机回环路由。
- README 截图更新（PR #3）。

## 第二版：设置页分组导航、搜索匹配度、Bot 详情页与自动审核校验

第二版对应提交 `f55b3ca7`（在第一版 `86c87a93` 之上合入 PR #10 / #11 / #13）。Android 版本号为 **`1.26.0-rokbot.15`**（versionCode 321215，签名证书 SHA-256 以 `46214d3d` 开头），可直接覆盖升级 321214 / 321213 / 321212 / 321211，安装包 SHA-256 为 `7ea0a2662dc6d9d161f6b7771b7bd44d12053b0d3431ad49fc04efab46ddbabe`；桌面端（macOS、Windows、Linux）与网页版升级到 **1.3.5**。通过自建 Host 的「更新」通道获取，无需重新配对。

### 设置页分组导航与「输入建议」滚动修复

- 桌面端与网页版的设置页改为分组导航：左侧分组列表、右侧内容，长设置页不再一直往下滚。
- 设置页里的「输入建议」不再吃掉滚轮：在建议列表上滚动会正常滚动页面，输入建议条本身可以滚动。
- 「数据迁移」在分组导航中位于第一级，Android、桌面端和网页版都能直接找到。

### Bot 详情页

- 桌面端与网页版新增 Bot 详情页：一个 Bot 的人设、模型与工具、自动化、记忆与用量集中在一页查看，不用来回切换。
- 详情页与 Bot 资料库共用同一份数据，改动后各处显示一致。

### 搜索返回值统一带匹配度与覆盖率

- Host 对 `searchAgents` / `searchMedia` 一律返回 `{ matches, coverage }` 结构，不再出现裸数组，Android 的搜索不再因为「回复格式不对」显示为不可用。
- 每条匹配带匹配度（match / relevance），并给出覆盖率 `coverage`（是否完整、是否还能继续翻页），界面据此提示「结果不完整」或继续加载。
- 搜索结果索引在缺失或损坏时自动重建，不再需要手动干预。

### 自动审核按官方 schema 整份校验（允许空 action_description）

- 自动审核的判定结果改为按官方 schema 整份校验，而不是只抽查少数字段。
- 放行（ALLOW）时官方允许返回空的 `action_description`，现在按允许处理，不再被误判为格式错误而回落。
- 校验不过时仍按原有逻辑重试一次，再失败才回落。

### 昨晚已在主干里的改动（第一版起持续生效）

- 输入建议 v2：建议按 Bot 学习你的使用习惯、在本地即时补全、建议条淡入上浮动画，可关闭学习并清除学习记录。
- 用量统计 v2：缓存写入的 Token 正确计入用量，用量页默认打开「今天」并有刷新反馈。
- Grok Bot 迁移：新增迁移向导，可从原版 Grok Bot 导入 Bot、会话与记忆。
- 安卓建群重写：建群流程重写，选择成员与确认更稳定。
- 缺失工具修复：修复部分场景下工具缺失导致的失败。
- iOS 对齐：iOS 客户端与新接口对齐。
- README 更新。

### 已知未处理项

- runner 侧自动审核的超时仍为 15 秒（`SAND_AUTO_REVIEW_CLASSIFIER_TIMEOUT_MS = 15000`）。模型响应较慢时，自动审核会超时并回落到手动确认；这一项本版未调整。
